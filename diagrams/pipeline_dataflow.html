Stage Legend

S0: WebUI Config — PipelineConfig / CLI args
S6: Backend Inference — YOLOv8s .pt / .onnx / TRT
S1: Video Source — cv2.VideoCapture (file / RTSP)
S7: Post-Process — class whitelist + cross-view NMS
S2: ROI Crop — RegionSetter bbox crop
S8: Tracker — ByteTrack (supervision)
S3: Motion Gate — MOG2 + CC filter on cropped frame
S9: Output — CBOR/MQTT · MJPEG · annotated video
S4: FEP Projection — fisheye → tangent views (optional)
Feedback — YOLO-gated lane calibration loop (S7→S3)
S5: Tiling — TileActivation 2×N grid split (optional)

Pipeline Notes

ROI crop (S2) is first: motion gating (S3) operates exclusively on the cropped sub-frame at 320×320 downscale, not on the full resolution input. This is necessary for valid lane calibration.

Motion gate (S3): frames where fg_score falls below threshold skip S4–S6 entirely, saving GPU cycles. The lane mask and calibration state are still maintained.

S4 (FEP) and S5 (Tiling) are optional; activated by --fep (fisheye cameras) or --force-tiles respectively. Without either, the cropped frame passes directly to S6.

YOLO-gated calibration: S7 feeds confirmed vehicle frame indices back to the Subtractor in S3. Only frames where YOLO detected a vehicle contribute to the lane accumulator, preventing tree/shadow contamination.

S9 (Output) renders the final composite onto the original full-resolution frame: ROI boundary, lane mask overlay, per-track bounding boxes, and hazard zone highlighting — matching the saved video output.
