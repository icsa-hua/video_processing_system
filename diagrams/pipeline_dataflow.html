Stage Legend

S1: Video Source — cv2.VideoCapture
S6: Post-Process — class filter + cross-NMS
S2: Motion Gate — MOG2 + CC quality filter
S7: Tracker — ByteTrack / SORT (supervision)
S3: Projection — FEP / PanoramaReprojector
S8: Hazard Logic — zone intersection + events
S4: ROI / Tiling — RegionSetter + TileActivation
S9: Output — MQTT CBOR / MJPEG / save
S5: Backend Inference — YOLO .pt / .onnx / TRT
Feedback — YOLO-gated lane calibration loop

Pipeline Notes

Motion gate runs at 320×320 downscale; frames without motion (fg_score below threshold) skip S3–S8 entirely, saving GPU cycles.

S3 is optional; enabled by --fep or --panorama. Without it the raw (or ROI-masked) frame passes directly to S4.

YOLO-gated calibration: only frames where S5 confirms a vehicle contribute to the MOG2 lane accumulator in S2, preventing tree/shadow contamination.

Backend Inference is the dominant latency stage. TensorRT (.engine) on Jetson is the target deployment path for sub-10 ms inference.

Drivable confidence map (S8) combines static lane mask, vehicle detection heatmap, and track trails to produce a continuous float32 map.
